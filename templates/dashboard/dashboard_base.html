ERP Help & Guide

Complete guide for school staff

Welcome to SPL ShalaSarthi

Use this guide to understand the main modules, common actions, and safe data-entry practices available to your school.

01

Dashboard

Your dashboard provides a quick overview of your school's ERP activities and important information.

  • Review important school information.
  • Check available ERP modules.
  • Use the sidebar to navigate between modules.
02

Student Management

Manage student records and maintain accurate student information.

  • Add Student – register a new student.
  • Student Records – view and manage existing records.
  • Verify student information before saving.
  • Avoid duplicate student records.
03

Certificates

Generate and manage official student certificates available to your school.

    {% if feature_modules.tc %}
  • Transfer Certificate – create and manage TC records.
    • {% endif %} {% if feature_modules.bonafide %}
  • Bonafide Certificate – create and manage bonafide records.
    • {% endif %}
  • Carefully verify student details before generating a certificate.
  • Review certificate information before printing or downloading.
{% if feature_modules.import_export %}
04

Import / Export

Use Excel files to efficiently manage large amounts of student data.

  • Download the latest ERP Excel template.
  • Enter data carefully in the provided columns.
  • Marathi, Hindi, English and other Unicode text can be entered where supported.
  • Do not rename required column headers.
  • Check the import preview and validation results before completing the import.
{% endif %} {% if feature_modules.attendance %}
05

Attendance

Manage student attendance records according to your school's academic workflow.

  • Open the Attendance module.
  • Select the required class/date.
  • Enter attendance accurately.
  • Review entries before saving.
{% endif %} {% if feature_modules.results %}
06

Marks & Results

Enter, manage and review student academic results where this module is enabled.

  • Select the appropriate academic context.
  • Enter marks carefully.
  • Review totals and results before saving.
  • Verify student details before finalizing.
{% endif %} {% if feature_modules.teachers %}

Teacher Management

Manage teacher information available to your school.

  • Maintain accurate teacher records.
  • Verify contact and profile information.
  • Keep records updated when changes occur.

Fee Management

Manage school fee-related operations available in your ERP.

  • Verify student information before transactions.
  • Review fee details carefully.
  • Keep payment-related information accurate.
{% endif %} {% if feature_modules.timetable %}
09

Timetable

Manage timetable information according to the modules enabled for your school.

  • Review timetable entries carefully.
  • Check classes and schedules before publishing.

Notice Board

Manage school notices and announcements available through the ERP.

  • Enter clear and accurate notice information.
  • Review the notice before publishing.

11

Reports

Use Reports to review available school data and generate required reports.

  • Select the required report.
  • Apply the required filters.
  • Review the data before exporting or printing.
12

Subscription & Account

Review your school's subscription-related information and payment history.

  • Check subscription status when required.
  • Review available payment history.
Important Data Safety
  • Always verify data before saving.
  • Do not share your ERP password or OTP.
  • Do not upload files containing unrelated or unauthorized information.
  • Avoid creating duplicate student records.
  • Log out when using a shared computer.
